## 配套演示项目说明

每个章节都配有对应的 Unity 演示场景与脚本，位于：

```
d:\Unity\Arch\unity\Assets\
├── Scripts\              # 教程示例脚本
│   ├── Common\           # 公共基础设施
│   ├── Chapter01\        # 第01章示例
│   ├── Chapter02\        # 第02章示例
│   └── ...
├── Scenes\               # 演示场景
│   ├── Chapter01.unity
│   ├── Chapter02.unity
│   └── ...
└── Prefabs\              # 预制体
```

**操作快捷键**（运行时可用）：
- `Space` / `N`：跳到下一章
- `B` / `P`：返回上一章
- `R`：重启当前章节
- `1`-`9`：直接跳到对应章节
- `F1`：切换 DebugHUD 显示
