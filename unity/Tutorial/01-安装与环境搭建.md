# 第01章 安装与环境搭建

## 1.1 前置要求

### 1.1.1 .NET 环境

Arch 是一个 C# 编写的 ECS 框架，支持以下运行时：

| 平台 | 最低版本 | 备注 |
|------|---------|------|
| .NET | 6.0 / 8.0 | 推荐使用 .NET 8 |
| .NET Standard | 2.1 | 用于 Unity / Godot 集成 |
| Unity | 2021.3 LTS+ | 需 .NET Standard 2.1 兼容 |
| Godot | 4.x (Mono) | 同上 |

> 💡 Arch 2.x 起依赖 `CommunityToolkit.HighPerformance`、`Collections.Pooled`、`Schedulers` 等库，安装时会自动拉取。

### 1.1.2 IDE 选择

- **Visual Studio 2022**（推荐，Windows）：完整的源生成器支持与调试体验
- **JetBrains Rider**：跨平台，源生成器调试极佳
- **VS Code**：搭配 C# Dev Kit

## 1.2 在普通 .NET 项目中安装

最简单的方式，通过 NuGet 安装：

```bash
# 命令行
dotnet add project package Arch --version 2.1.0-beta

# 或使用 PackageReference
<PackageReference Include="Arch" Version="2.1.0-beta" />
```

如需扩展功能，可继续安装：

```xml
<PackageReference Include="Arch.System" Version="*" />
<PackageReference Include="Arch.System.SourceGenerator" Version="*" />
<PackageReference Include="Arch.LowLevel" Version="*" />
<PackageReference Include="Arch.Persistence" Version="*" />
<PackageReference Include="Arch.Relationships" Version="*" />
<PackageReference Include="Arch.EventBus" Version="*" />
```

## 1.3 在 Unity 中安装

Unity 不能直接使用 NuGet，需要按以下步骤操作：

### 方案一：使用 NuGetForUnity（推荐）

1. 在 Unity 中打开 `Window > Package Manager`
2. 点击 `+` → `Add package from git URL...`
3. 输入：`https://github.com/GlitchEnzo/NuGetForUnity.git`
4. 安装完成后，菜单 `NuGet > Manage NuGet Packages`
5. 搜索并安装以下包：
   - `Arch`
   - `CommunityToolkit.HighPerformance`
   - `Collections.Pooled`
   - `Schedulers`
6. 若需源生成器扩展，还需要：
   - `Arch.System`
   - `Arch.System.SourceGenerator`（需将其设为 Roslyn analyzer，见下文）

### 方案二：手动放置 DLL

1. 使用命令行构建 Arch 的 nupkg：
   ```bash
   cd d:\Unity\Arch\Arch\src\Arch
   dotnet pack -c Release
   ```
2. 解压生成的 `.nupkg`（实为 zip），取出 `lib/netstandard2.1/Arch.dll`
3. 在 Unity 项目中创建 `Assets/Plugins/Arch/` 目录
4. 将以下 DLL 全部拷入该目录：
   - `Arch.dll`
   - `CommunityToolkit.HighPerformance.dll`
   - `Collections.Pooled.dll`
   - `Schedulers.dll`
   - `System.Runtime.CompilerServices.Unsafe.dll`（若 Unity 未自带）
5. 在 Inspector 中确认每个 DLL 的平台设置：
   - `Any Platform` ✅
   - `Exclude Platforms`：无
   - `Api Compatibility Level`：`.NET Standard 2.1` 或 `.NET 4.x`

### 方案三：直接引入源码（学习源码推荐）

> 💡 本教程配套的 `d:\Unity\Arch\unity` 项目即采用此方案，便于源码学习与断点调试。

1. 将 `d:\Unity\Arch\Arch\src\Arch\` 下的所有 `.cs` 文件拷贝到 `Assets/ArchSource/Core/`
2. 将 `d:\Unity\Arch\Arch\src\Arch\Pollyfilling\` 拷贝到 `Assets/ArchSource/Pollyfilling/`
3. 通过 NuGetForUnity 安装运行时依赖（`CommunityToolkit.HighPerformance` 等）
4. 修改 `ProjectSettings/ProjectSettings.asset` 中的 `apiCompatibilityLevelPerPlatform` 为 6（.NET Standard 2.1）

### 1.3.1 启用源生成器（可选，进阶用）

若要使用 `Arch.System.SourceGenerator`：

1. 在 NuGet 下载 `Arch.System.SourceGenerator` 包
2. 解压取 `analyzers/dotnet/cs/Arch.System.SourceGenerator.dll`
3. 放入 `Assets/Plugins/Arch/SourceGenerator/`
4. 在 Inspector 中，将该 DLL 的：
   - `Select platforms for plugin` → `Any Platform` 取消勾选
   - `Asset Labels` → 添加 `RoslynAnalyzer`
5. 在 `ProjectSettings/ProjectSettings.asset` 中追加：
   ```yaml
   - name: Arch.System.SourceGenerator
     enabled: 1
   ```

## 1.4 启用 PURE_ECS 模式（可选）

> 🔥 PURE_ECS 模式可让 `Entity` 结构体缩小为 8 字节（仅 Id + Version），适合内存敏感场景。

### 普通项目

在 `.csproj` 中：

```xml
<PropertyGroup>
  <DefineConstants>PURE_ECS</DefineConstants>
</PropertyGroup>
```

### Unity 项目

1. `Edit > Project Settings > Player > Other Settings`
2. 在 `Scripting Define Symbols` 中添加 `PURE_ECS`
3. 点击 Apply

启用后，[Entity.cs](file:///d:/Unity/Arch/Arch/src/Arch/Core/Entity.cs#L8) 中的 `#if PURE_ECS` 分支会被激活，实体不再携带 `WorldId` 字段：

```csharp
// PURE_ECS 模式下：
public readonly struct Entity
{
    public readonly int Id = -1;       // 4 字节
    public readonly int Version;        // 4 字节
    // 总共 8 字节
}

// 默认模式：
public readonly struct Entity
{
    public readonly int Id;             // 4 字节
    public readonly int WorldId;        // 4 字节
    public readonly int Version;        // 4 字节
    // 总共 12 字节
}
```

> ⚠️ PURE_ECS 模式下，无法通过 `Entity` 直接访问 World，必须显式持有 World 引用。混合使用会导致编译错误。

## 1.5 验证安装

在 Unity 项目中创建测试脚本 `InstallationTest.cs`：

```csharp
using Arch;
using UnityEngine;

public class InstallationTest : MonoBehaviour
{
    private void Start()
    {
        using var world = World.Create();
        var entity = world.Create();
        Debug.Log($"Arch 工作正常！实体 ID: {entity.Id}");
    }
}
```

挂载到任意 GameObject 并运行，控制台输出类似如下即代表安装成功：

```
Arch 工作正常！实体 ID: 0
```

## 1.6 项目结构总览

完成安装后，建议的项目结构如下：

```
YourProject/
├── Assets/
│   ├── Plugins/
│   │   └── Arch/                  # Arch 运行时 DLL
│   ├── Scripts/
│   │   ├── Components/            # 自定义组件
│   │   ├── Systems/               # 系统逻辑
│   │   └── GameMain.cs            # 入口
│   └── Scenes/
│       └── Main.unity
└── Packages/
    └── manifest.json
```

## 1.8 本章小结

| 关键点 | 说明 |
|-------|------|
| Arch 支持 .NET 6/8 与 .NET Standard 2.1 | Unity 2021.3+ 即可使用 |
| Unity 推荐用 NuGetForUnity 安装 | 或手动拷贝 DLL |
| 源生成器需手动配置 RoslynAnalyzer | 才能在 Unity 中生效 |
| PURE_ECS 可缩小实体至 8 字节 | 但需显式持有 World 引用 |
